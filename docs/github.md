# GitHub 页面文字

## 推荐仓库名

`whale-girl-touchbar`

## About 简介

带有鲸鱼娘与三花猫的原生 macOS Touch Bar 桌宠，支持触摸互动、28 段动画和可选 DSH 任务联动。

Native macOS Touch Bar companion with a whale girl, a calico cat, 28 animation clips, and optional DeepSeek Harness integration.

## 推荐 Topics

`macos` `touchbar` `desktop-pet` `objective-c` `deepseek-harness`

## 首页应保留的信息

- 需要物理 Touch Bar，普通 Mac 键盘不能替代。
- 离线本地陪伴可直接使用；DSH 联动为可选安装。
- 模型调用需要使用者自己的 DSH 配置，自动调用默认关闭。
- 当前实际硬件验证范围与签名状态。
- 上游动画作者和非商业素材许可。

推荐首个标签：版本确认为 `12.0.2` 时使用 `v12.0.2`。创建 Release 前参考 [发布流程](releasing.md)，不要把源码归档称为可直接安装的应用。
