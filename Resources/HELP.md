# 鲸鱼娘与三花猫 · 使用帮助

点击菜单栏的小鱼图标打开面板。Touch Bar 上轻触角色可以互动，长按摸头，按住拖动；最右侧圆圈打开系统音量与亮度组件，点「返回桌宠」回来。

动作库提供28段完整PC2005动作，皮肤开关可切换原版与PC2005外观。角色真正横移时使用侧身步态；切换动作保持共同人物比例，猫咪可以独自游玩。

应用本地陪伴不依赖DSH。任务状态、聊天、碎碎念和余额需要另行安装本项目的DSH桥接，并在DSH内配置自己的模型。聊天和碎碎念仅在主动点击时调用模型，可能产生费用；自动调用默认关闭。

登录自启是可选功能。暂停、退出、锁屏和睡眠会停止本应用的Touch Bar显示。应用不修改原系统Touch Bar文件。

本项目需要带有物理Touch Bar的MacBook，使用私有系统接口；具体系统版本的兼容性请参阅对应发布说明。
